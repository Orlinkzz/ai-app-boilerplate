# Contoh: Laravel + React

Ini contoh cara mengisi template untuk satu stack nyata:

- `AGENTS.example.md` — `AGENTS.md` yang sudah terisi (proyek, stack, perintah, struktur, konvensi)
- `Makefile.example` — isi target `setup/dev/test/lint/build`

Cara pakai: salin isinya ke root proyekmu (ganti nama jadi `AGENTS.md` / `Makefile`), lalu sesuaikan.

> Catatan: contoh ini ditulis sebagai titik awal dan **belum dijalankan di proyek Laravel sungguhan**.
> Nama perintah dan versi paket bisa berbeda di proyekmu. Namanya sengaja `*.example` agar
> tidak terbaca otomatis oleh AI tool sebagai instruksi repo ini.
